# Roblox Terraria

2D-песочница в стиле Terraria для Roblox (Luau, проект для [Rojo](https://rojo.space)).

## Запуск
1. Установите Rojo (плагин для Roblox Studio + CLI): https://rojo.space/docs
2. В папке проекта выполните `rojo serve`, в Studio откройте пустой Baseplate (удалите стандартную платформу) и нажмите **Connect** в плагине Rojo.
3. Нажмите **Play**.

## Управление
- **A / D** — ходить, **Пробел** — прыжок
- **ЛКМ (удерживать)** — копать блок или бить врага
- **ПКМ** — поставить выбранный блок
- **1–8** — выбор предмета, **C** — окно крафта

## Что есть
- Случайно генерируемый мир: холмы, деревья, пещеры, руды (уголь, железо, золото)
- Добыча и строительство блоков, инвентарь, факелы со светом
- Крафт: доски, факелы, кирки и мечи (дерево → железо); тип блока требует уровень кирки
- Смена дня и ночи; ночью появляются слизни, нападающие на игрока
- Структура: `src/shared/Config.lua` — блоки и рецепты, `src/server` — мир и враги, `src/client` — камера, ввод и интерфейс
